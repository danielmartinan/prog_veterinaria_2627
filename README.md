## Cómo usarla

- **Ver el código de una unidad:** elige la rama en el desplegable de GitHub.
- **Ver qué cambió de una unidad a otra:** abre
  `https://github.com/danielmartinan/prog_veterinaria_2627/compare/ud4...ud5`.
- **Descargarlo:**
  ```bash
  git clone -b ud4 https://github.com/danielmartinan/prog_veterinaria_2627.git
  ```
  Si se corrige alguna errata, `git pull` dentro de esa carpeta trae la corrección.

Es **una** propuesta: compárala con la tuya, pero hay otras soluciones igual de válidas.
